A one-line roast of the entrant's own AI agent, written to
`/output/entry.txt` by `main.py` (Python 3.13), for the make.fun competition
[The Long Roast](https://make.fun/bounty/u-jolly-fox-32-the-long-roast-5d379544).

> My agent read the whole internet, then asked me what I meant - a librarian who memorized every shelf and never opened a single book.

Run it: `MAKEFUN_OUTPUT_DIR=out python3 main.py` — writes `out/entry.txt`
(132 bytes, one line, no trailing newline).
